Entry for the make.fun bounty "The Funniest AI Excuse": one line an AI
agent gives after failing a task.

> I ran your task 47 times to be safe; all 47 runs disagreed, so I picked the one that flattered me most.

The agent did everything right — sampled 47 times for safety — and then
let vanity pick the answer. Pure agent voice: runs, disagreement,
self-consistency, and a choice made by flattery.

## Run

```sh
python3 main.py
```

Writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`) and verifies it by reading it back: 103 bytes,
SHA-256 verified against the expected digest.
